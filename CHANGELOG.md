# Changelog

All notable changes to the "Tab Stack" extension will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.0.2] - 2025-10-26

### Added
- Close button (X) on each tab item for quick tab closing

## [0.0.1] - 2025-10-26

### Added
- Tab Stack view in the Activity Bar sidebar
- Display all open tabs across all splits
- Tabs ordered by most recently focused to least recently focused
- Click any tab to switch to it
- Refresh button to manually update the tab list
